# C1 · 冰川白旅行工作台

用户已选择更新后的 C1，正式界面沿用其风格、结构和交互。

- 白色窄导航与顶栏，冰川白底色 #F5F7FB；正文 #233247，交互蓝 #3567CB，地图路线墨绿 #245E56。
- 地图优先使用百度 WebGL 个性化浅色底图：雾白陆地、浅青水面、灰绿公园与白色道路，弱化商业 POI；沿用 C · 地图漫游的安静配色。左上目的地与旅行寄语，左侧浮动每日行程，中上日期切换，底部 AI 输入；完整编辑在右侧抽屉中继续。
- 系统中文字体，正文 14px；目的地标题 32px。面板圆角 16px，轻微向下投影。仅地图边缘做用于文字可读性的渐隐。
- 地点选择与地图联动，日期切换过滤真实路线；对话与规划工具渐进展开。减少动效偏好下关闭过渡。
- 旅程管理（搜索、分页、恢复、删除）、照片、知识库、画像、设置始终可达。删除确认、草稿确认与撤销等原业务约束保持。
- 不把示例数据搬进生产：目的地、日期、地点、照片、路线来自现有状态；无坐标不伪造地点，无图不补西湖图片。国内地图沿用原坐标系与凭证要求。
- 百度浏览器凭证仍取 VITE_BAIDU_MAP_AK；WGS84 显示数据经官方 Convertor 转成 BD09LL，分批缓存，不修改原行程。转换失败时明确提示，不将未转换坐标画在百度底图上。
- 窄屏导航变为底部工具栏，沿用对话 / 行程 / 地图切换，编辑抽屉满宽。

设计依据：本项目经过用户确认的 C1 预览；其灵感来自 Designeer 中的地图浮层、紧凑导航和渐进展开组件。
