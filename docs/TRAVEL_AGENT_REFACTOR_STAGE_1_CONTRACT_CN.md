# SuperTravelAgent 重构阶段 1：V3 契约冻结

> 日期：2026-07-17
> 分支：`codex/travel-product-refactor`
> 状态：用户验收通过

## 1. 本阶段结果

- 新增严格的 `TravelPlanDocumentV3`，统一旅行意图、目的地、交通、住宿、日程、候选、地图、预算、行动项、来源和交付数据。
- 新增规划事件公共信封、事件类型、载荷约束及完整中文状态映射。
- 新增确定性的 V2→V3 只读适配器；旧数据缺少证据或实时核验时只会降级，不会被提升为实时信息。
- 固化旅行文档与规划事件的 JSON Schema 快照，后续不兼容修改会直接导致契约测试失败。
- 增加国内 3 日和国际 5 日固定样本；国际样本覆盖当地时间/北京时间与原币/人民币参考金额。
- 前端增加对应的 V3 类型与中文状态契约，为后续唯一状态容器做准备。

## 2. 关键真实性约束

- 具体车次、航班、时刻和余票只有在 `realtime_verified` 时才允许进入正式选项。
- 没有稳定地点信息的旧活动迁入候选池，不进入正式地图。
- 候选活动不能携带日序、时间或固定状态，默认不显示在正式地图。
- 可用路线必须包含 Provider 与真实几何；本阶段不会用直线伪装路线。
- 可导出图片不能同时要求署名；没有明确导出许可时只保留在线展示信息。
- 地图正式地点必须与当前正式日程和锚点精确一致，拒绝陈旧地点 ID。
